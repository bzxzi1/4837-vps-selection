先说一个很容易被忽略的细节：**AS4837 是网络自治系统编号，不是服务器硬件规格，也不意味着服务器自己的 IP 一定属于 AS4837。** 公开 BGP 数据显示 AS4837 对应 CHINA169-Backbone，也就是中国联通的骨干网络；VPS 商家说“4837 VPS”，更多是在描述跨境回程所采用的网络路径。

## 4837 VPS 到底指什么？

AS4837 目前对应 CHINA169-Backbone，由中国联通运营。

因此，一台美国 VPS 的“4837”通常应该拆成两个概念来看：

**第一层是线路。**
例如 LisaHost 当前美国 4837 产品页明确写的是“三网回程 CUVIP 4837 线路优化”，也就是产品将回中国大陆方向的网络路径作为主要卖点。

**第二层是服务器 IP。**
服务器本身拿到的公网 IPv4，可以属于另外一个 ASN。这个区别在实际检测中非常明显：2026 年 7 月一篇针对 LisaHost 美国 4837 基础版的 NodeSeek 实测里，被检测 IP 的 ASN 显示为 **AS2914 / NTT America**，而不是 AS4837；但该产品的回程路由仍然可以经过 AS4837。

所以不要看到某个 IP 的 ASN 不是 4837，就直接判断“这不是 4837 VPS”；反过来，也不要看到一个 VPS 写着“4837”，就默认它在所有方向、所有时间段都走完全一样的路径。

## 4837 线路实际表现，应该怎么看？

这里最好不要把商家的线路描述和独立测试混成一件事。

LisaHost 当前产品页宣称的是三网回程 CUVIP 4837，并强调美国洛杉矶节点、双 ISP 家宽住宅 IP、大带宽以及部分方案不限流量。

第三方测试则给出了更加具体、同时也更加复杂的结果。

2026 年 6 月的一篇 LisaHost 美国 4837 实测文章记录了晚高峰测试，其中作者报告联通方向最低延迟约 161ms，测试整体丢包低于 2%；同一篇测试还报告了流媒体和 AI 服务的访问结果。由于这是单台机器、单个 IP、单个测试时间段的数据，不能把它理解成所有套餐和所有地区用户都能拿到的固定数值。

另一个更值得注意的样本来自 2026 年 7 月 NodeSeek。测试机器的 IP 质量检测显示，不同数据库对同一个 IP 的分类并不完全一致：多项数据库给出“家宽”属性，但 IP2Location 同时标记为机房用途；风险数据库中该测试 IP 没有被列入黑名单，不过本地 25 端口出站被检测为阻断。

这说明了购买这类 VPS 时一个很现实的问题：

> **“住宅 IP”不是所有 IP 数据库都会给出完全一致的标签，线路质量也不是一个套餐名就能保证的。**

因此，对 TikTok、AI 服务、流媒体或者跨境电商这类依赖 IP 属性的用途，真正重要的是你拿到的**具体 IP**，而不只是产品页面上的分类。

## 常见问题

### 4837 和 9929 有什么区别？

两者都是中国联通体系中的网络标识，但不是同一个 ASN。当前公开 BGP 数据把 AS4837 标为 CHINA169-Backbone；LisaHost 目前也分别提供 4837 和 9929 产品组。

实际选择时，与其先背线路名称，不如比较具体套餐给出的带宽、流量、IP 类型、机房位置以及你所在运营商到该节点的真实路由。

### 电信和移动用户能不能用 4837？

LisaHost 当前 4837 产品页面明确宣传的是“三网回程 CUVIP 4837”，因此产品设计目标并不只针对联通宽带。

但“三网都接入”不代表三家运营商在每个省份、每天每个时段的体验完全相同。公开测试里不同运营商、不同目的地的路径和时延就存在差异。

### 住宅 IP 一定比数据中心 IP 更好吗？

不能简单这么说。

如果你的业务依赖平台对 IP 使用类型的判断，住宅属性可能很重要；但“住宅”标签本身也需要具体 IP、具体数据库来验证。2026 年的实测已经出现多个 IP 数据库对同一个地址给出不同类型判断的情况。

### 4837 VPS 能不能用于 Netflix、TikTok 或 ChatGPT？

公开测试确实出现过成功结果，包括 Netflix、TikTok 和 ChatGPT。

不过这类服务的地区可用性与 IP 风控会变化，因此不要把一次测试当成长期保证。对这类需求，实际拿到的 IP 比产品标题更重要。
